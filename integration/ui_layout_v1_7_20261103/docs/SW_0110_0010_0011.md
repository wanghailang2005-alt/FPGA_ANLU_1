# SW=0110 滑动方向、SW=0010 滚动速度、SW=0011 滚动方向

版本：V1.1  
日期：2026-11-01  
基线：`zoom_animation(1).rar`（`ZOOM_CACHE_CHECK_20261029` 对应源码快照）  
改动范围：仅 `user_control.v`、`image_transition.v`、`osd_overlay.v`、`osd_status_layout.v`、`osd_font_rom.v`、`top_tf_hdmi_audio.v`  
未改动：SD/BMP 读取、SDRAM 缓存、缩放、PLL、约束、`.al` 工程文件清单（没有新增源文件）

## 1. 本次开放的设置项

| SW 编码 | 设置项 | K3 循环顺序 | 默认值 | HUD 显示 |
|---|---|---|---|---|
| `0001` | 文字显示模式 | 关闭(0) → 固定 OSD(1) → 滚动字幕(2) → 两者同时(3) | 3 两者同时 | `SW:0001 V=4` |
| `0010` | 滚动速度 | 慢 1 像素/帧(0) → 中 2(1) → 快 4(2) | 0 慢 | `SW:0010 V=1` |
| `0011` | 滚动方向 | 向左(0) → 向右(1) | 0 向左 | `SW:0011 V=1` |
| `0110` | 滑动方向 | 向左(0) → 向右(1) | 0 向左 | `SW:0110 V=1` |

`0100`（转场效果）、`0101`（转场时长）、`0111`（最近邻缩放）、`1000`（双线性缩放）保持原样，未做改动。

`0001` 是本轮一并补上的：没有它，滚动字幕无法单独开关，`0010`/`0011` 也就无法在板上分别确认。
若要求符合任务书“默认文字关闭”，把 `user_control.v` 的 `TEXT_MODE_RESET` 参数改成 `2'd0` 即可；
当前默认 `2'd3` 是为了保持你原来上电就能看到固定状态行 + 滚动字幕的观感，避免看起来像“功能丢了”。

## 2. 行为说明

### 2.1 滑动转场方向（SW=0110）

- `image_transition.v` 新增 `slide_dir` 输入。
- `slide_dir=0`：黑幕自右向左推入（可见区在左侧 `x < slide_pos`），新图自左向右揭开——**与改动前完全一致**。
- `slide_dir=1`：黑幕自左向右推入（可见区在右侧 `x >= 640-slide_pos`），新图自右向左揭开。
- 方向和 `mode` / `duration_sel` 一样在**切图请求被接收时锁存**：转场进行中拨 SW=0110 只影响下一次切图，不会让当前这次转场中途换向。
- 时序、延迟、DE/HS/VS 完全没有变化，仍然是组合输出，不增加拍数。

### 2.2 滚动字幕速度与方向（SW=0010 / 0011）

`osd_overlay.v` 的滚动部分重写为参数化的跑马灯：

- 字幕串 `WELCOME TO ANLU FPGA`，20 字符 × 8 像素 = 160 像素宽，位于第 448~463 行。
- 内部用 `text_pos`（= 字幕左边缘 + 160 的偏置值，范围 0~800）表示位置：
  - `0` = 左边缘在 x=-160（完全移出左侧）
  - `800` = 左边缘在 x=+640（完全移出右侧）
- **向左**：每帧 `text_pos -= step`，减到 0 后跳回 800，从右侧重新进场。
- **向右**：每帧 `text_pos += step`，加到 800 后跳回 0，从左侧重新进场。
- `step` = 1 / 2 / 4 像素，由 SW=0010 选择，对应任务书的“每帧移动 1/2/4 像素”。
- 位置**只在帧消隐边界更新一次**（VS 起始沿且 DE=0），一帧有效区内保持不变，不会半帧撕裂。
- 方向改变时**保留当前位置**，从下一帧起反向移动，符合任务书 6.5 的要求。
- 复位后 `text_pos=800`（完全在右侧之外），默认向左进场。

原来的实现每 2 帧才走 1 像素，且只能向左、无法关闭；现在三档速度和两个方向都由 SW 控制。
滚动速度/方向是立即生效的（下一帧开始），文字模式在帧边界锁存。

### 2.3 状态栏第三行

`osd_status_layout.v` 增加第三行 `SW:xxxx V=n`（y=64~79，x=16~103），
显示当前 SW 编码和该设置项的值（1 起编号）。为此 `osd_font_rom.v` 补了一个 `=`（0x3D）字形。
这一行可以现场确认“按了几次 K3、现在是什么值”，也满足任务书 4.3 的“OSD 显示当前设置项和值”。

注意：显示的是**设置值**，不是“正在生效值”。转场/缩放的参数要等下一次切图才生效，
这一点和任务书 4.3 最后一行的区分要求一致，但当前 HUD 没有额外做 busy 提示。

## 3. 跨时钟域

`user_control` 在 `clk`（50 MHz）域，OSD 在 `video_clk` 域：

- `{setting_value, text_mode, scroll_dir, scroll_speed}` 打包成 9 位，经 `osd_status_cdc`（打包数据邮箱）
  一致快照送到 `video_clk` 域，**不是**逐位同步。
- `sw_code` 复用已有的 `u_diag_sw_video` 通道。
- `slide_dir` 直接进 `image_transition`，模块内部做两级同步并在请求沿锁存。

## 4. 板上验证步骤

1. 用 TD 重新综合、实现并下载（本次没有重新生成 bit，见第 6 节）。
2. 保持 K2/K4 原功能：K2 下一张、K4 轮播启停不变。
3. **滑动方向**：SW=`0100` 按 K3 两次切到“滑动”，再拨 SW=`0110`，每按一次 K3 切换向左/向右，
   然后按 K2 切图观察黑幕从哪一侧推入。右上角第三行应显示 `SW:0110 V=1/2`。
4. **滚动速度**：拨 SW=`0010`，按 K3 逐档切换，底部滚动字幕速度应变成 1/2/4 像素每帧。
5. **滚动方向**：拨 SW=`0011`，按 K3 切换左右；字幕应在反向瞬间**停在原地**再从另一侧继续走。
6. **文字模式**：拨 SW=`0001`，按 K3 依次确认 关闭 / 只固定 OSD / 只滚动字幕 / 两者同时。
7. 按 K1 复位，应回到：文字模式 3、滚动慢速向左、滑动向左、直接切换、中等等长、最近邻。
