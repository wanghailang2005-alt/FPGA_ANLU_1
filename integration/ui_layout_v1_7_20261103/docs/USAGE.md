# 新UI操作说明

当前画面位置及操作变化以 [UI_LAYOUT.md](UI_LAYOUT.md) 为准。按键和拨码循环沿用下表；频谱改为常驻，SW=1001不再切布局；原欢迎滚动条和底部调参提示已由独立字幕带与右栏反馈取代。下方为历史V1.6说明，其显示位置表不再适用。

# V1.6 功能使用表

新增紧凑频谱模式，使用方法和验证见 [SPECTRUM.md](SPECTRUM.md)。V1.6新bit待上板验收；V1.5板测记录属于历史基线。

拨码顺序为 **SW4 SW3 SW2 SW1**，拨上为 1。先拨到对应功能，稳定后按 K3 调整；参数独立保存，长按不连发。

| 按键 | 功能 |
|---|---|
| K1 | 系统复位，恢复默认设置（RTL 端口 rst_n） |
| K2 | 下一张图片（RTL 端口 key1） |
| K3 | 调整拨码选中的设置（RTL 端口 key3） |
| K4 | 开启/关闭自动轮播（RTL 端口 key2，默认关闭） |

| SW | 功能 | K3 循环顺序 | 默认 |
|---|---|---|---|
| 0001 | 普通文字 | 关闭 → 固定状态 → 底部滚动条 → 两者同时 | 两者同时 |
| 0010 | 滚动速度 | 慢 1 → 中 2 → 快 4 像素/帧 | 慢 |
| 0011 | 滚动方向 | 向左 ↔ 向右 | 向左 |
| 0100 | 转场 | 直接 → 淡出淡入 → 水平滑动 → 风车旋转 → 垂直擦除 → 百叶窗 → 圆形光圈 → 方块溶解 | 直接 |
| 0101 | 转场时长 | 15 → 30 → 60 帧 | 30 帧 |
| 0110 | 转场方向 | 左/右；也控制垂直擦除方向 | 向左 |
| 0111 | 最近邻缩放 | 原尺寸居中 → 等比例留边 → 铺满裁剪 | 原尺寸 |
| 1000 | 双线性缩放 | 原尺寸居中 → 等比例留边 → 铺满裁剪，带缩放动画 | 原尺寸 |
| 1010 | 亮度 | 0～10 递增，10 后回 0 | 5，中性 |
| 1011 | 对比度 | 0～10 递增，10 后回 0 | 5，中性 |
| 1100 | 逐图双语字幕 | 关闭 → 中文 → 英文 → 双语 | 双语 |
| 1001 | 小板块音频频谱 | 直接进入：左下中英字幕、右下32柱频谱；K3无操作，拨回其他档退出 | — |
| 0000、1101～1111 | 未分配设置 | K3 无操作，继续显示当前图片 | — |

复位默认双语，因此第一次在 1100 按 K3 会关闭字幕。0001 不控制逐图字幕；0010/0011 同时影响中文字幕和底部滚动条。缩放时等待当前动作完成再按 K3；4:3 图片的留边与铺满目标相同。

| 显示层 | 位置/内容 |
|---|---|
| 固定状态 | 左上角 IMG / AUTO / SW 与设置值 |
| 中文 | y=400～415，16×16 点阵跑马灯，切图后重新进场；1001时裁剪至x=16～335 |
| 英文 | y=424～439，32 字符窗口静态标题；1001时窗口x=48～303 |
| 底部条 | y=448～463，欢迎文字；调节亮度/对比度时显示参数提示 |
| 音频频谱 | 仅1001：x=352～623/y=384～447，32柱最高40像素，真实输出PCM驱动 |

| 图片序号 | 默认场景 | 英文标题 |
|---|---|---|
| 1 | 宏村月沼 | HONGCUN MOON POND |
| 2 | 承志堂木雕 | CHENGZHI HALL CARVING |
| 3 | 历史老照片 | HONGCUN OLD PHOTOS |
| 4 | 徽派马头墙 | HUI HORSE-HEAD WALL |

非1001时，英文窗口保持原x=160～415；1001时在左侧字幕卡中居中。更换素材需要同步更新字幕；生成脚本尚有绝对路径和标记匹配问题，见V1.5板测记录。当前频谱音源为内部测试音阶，未新增TF音频播放。
