# 2026-10-28 最近邻缩放：BOARD PASS

用户最终确认“全部测试通过”。后续开发基线为本地 zoom_black2，bit 为 ZOOM_BLACK2_20261028.bit；精确哈希见[版本清单](versions.json)。

## 功能与操作

支持宽高各1–1024的24位无压缩、正高度BMP，处理4字节行对齐；输出640×480。K1复位、K2切图、K4轮播；SW4..SW1=0111时K3依次切换原尺寸居中→等比例留边→铺满裁剪。640×480原图三模式相同；4:3图的留边与铺满相同；321×481图适配后约320×480，与原尺寸居中差异很小。

## 故障与验证记录

## 恢复与重现

以本地 hdmi_async_exp_20261028 完整工程为基底，在副本执行 git apply --check --ignore-space-change nearest_from_async_baseline.patch 后以相同参数应用（基线部分文件使用CRLF）。七个自研源文件也以原目录结构保存。沿用原厂商IP、约束、OSD字库等依赖；TD工程需纳入新增 scale_on_load.v 和 zoom_diagnostics.v，参考本地最终工程文件清单。补丁不包含厂商工程配置，单独克隆不能直接构建整机bit。

最终核心/加载/复位脚本为 sim/run.do、card.do、reset.do；在sim目录用ModelSim执行。storage/display/controls脚本为保留的诊断回归入口，需要本地完整工程及相应厂商FIFO/字库依赖；其证据来自zoom_fix，不冒充本轮重跑。完整构建日志和最终源码清单见 evidence/final。

本地最终完整工程、bit、源码、测试、日志及构建脚本另存 archives/20261028_ZOOM_BLACK2_BOARD_PASS；厂商工程、加密IP、bit和数据库不上传GitHub。历史版本保留原路径。测试素材使用原水果BMP转换版本，不再使用条纹素材；素材及转换脚本位于本地zoom_fix/fruit_bmp和convert_fruit_assets.py。
