# 八种转场效果（SW=0100）

版本：V1.4  
日期：2026-11-03  
基线：`zoom_animation_bilingual_subtitle.zip`（V1.3）  
改动文件：`image_transition.v`、`user_control.v`、`top_tf_hdmi_audio.v`  
未改动：OSD、字幕、缩放、读卡、SDRAM、PLL、约束、`.al` 工程源文件清单

## 1. 效果清单

`SW=0100` 下按 K3 循环 8 档，状态栏第三行显示 `SW:0100 V=n`：

| V | transition_mode | 效果 | 观感 |
|---:|---:|---|---|
| 1 | 0 | 直接切换 | 瞬时切换 |
| 2 | 1 | 淡出淡入 | 画面渐黑→新图渐显 |
| 3 | 2 | 水平滑动 | 黑幕左右推入/揭开（`SW=0110` 控制方向） |
| 4 | 3 | 风车旋转 | 四片扇形从中心收拢/张开 |
| 5 | 4 | **垂直擦除** | 黑幕上下推入/揭开（`SW=0110` 控制方向） |
| 6 | 5 | **百叶窗** | 15 条 32 行的横带同时收拢/张开 |
| 7 | 6 | **圆形光圈** | 画面从中心收成一个点，再从点张开 |
| 8 | 7 | **方块溶解** | 64×64 分块按伪随机顺序逐块消失/出现 |

每种效果都是「旧图 → 全黑 → 换缓冲 → 新图」两段式，前后各用 `SW=0101` 选定的帧数
（短 15 / 中 30 / 长 60 帧）。全黑那一帧正好在缓冲区切换时，所以看不到撕裂。

## 2. 算法

所有几何转场共用一条归一化进度 `frac`（0~1024，由帧序号除以总帧数得到），
再派生出各效果自己的边界量，`frac=1024` 时正好是"满屏可见"的端点：

| 效果 | 参数 | 可见条件 |
|---|---|---|
| 水平滑动 | `slide_pos` 0~640 | `dir=0: x < slide_pos` / `dir=1: x >= 640-slide_pos` |
| 垂直擦除 | `vert_pos` 0~480 | `dir=0: y < vert_pos` / `dir=1: y >= 480-vert_pos` |
| 风车旋转 | `T` 0~320 | `min(|dx|,|dy|)*256 < max(|dx|,|dy|)*T` |
| 百叶窗 | `blind_pos` 0~32 | `(y & 31) < blind_pos` |
| 圆形光圈 | `R²` 0~160768 | `dx² + dy² <= R²` |
| 方块溶解 | 阈值 0~128 | `((idx*37) & 127) >= 阈值`，`idx = (y/64)*10 + x/64` |

`dx = x-320`、`dy = y-240`。方块溶解的块号用 `idx*37 mod 128` 打散，
80 个块得到 80 个互不相同的顺序值，所以是"逐块"消失而不是成片消失。

## 3. 资源与时序

- 本次把原来每个效果各自一份的 `/15`、`/30`、`/60` 除法收敛成**一套 3 个除法**，
  原来有 9 个（淡化/滑动/风车各 3 个），这一项是净节省；
- 新增乘法器：圆形光圈 2 个（`dx*dx`、`dy*dy`，10×10）。方块溶解的 `×10`、`×37`
  都是常数乘，综合成移位加；
- 全部在 `video_clk`（25 MHz）域，组合路径只有查表 + 比较，时序压力小；
- 以 TD 报告为准（原工程 LUT 约 55%、DSP 22/29）。

## 4. 板上验证

1. TD 重新综合实现、下载（本包不含 bitstream）。
2. 拨 `SW=0100`，连按 K3 走完 8 档，每档按 K2 切图观察效果。
3. 第 3 档（水平滑动）和第 5 档（垂直擦除）拨 `SW=0110` 再按 K3，方向应一起翻转。
4. 第 2 档转场较慢时，`SW=0101` 切到"长"（60 帧）更容易看清；`SW=0110` 的风车不受方向影响。
5. 按 K1 复位，回到第 1 档（直接切换）。

## 5. 已知取舍

- 所有效果都是"单图 + 黑场"过渡，**不是两图交叉**。这是当前单帧缓存架构决定的：
  切图期间只有一个缓冲区有效，做不到新旧两张图同屏混合。要做交叉淡化得再加一路读缓冲，
  属于第二轮改动。
- 风车是扇形擦除，不是把图像本身旋转；方块溶解是块级遮罩，不是马赛克渐变。
