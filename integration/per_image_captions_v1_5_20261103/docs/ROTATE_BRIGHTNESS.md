# 风车转场、亮度/对比度调节

版本：V1.2  
日期：2026-11-01  
基线：`zoom_animation_sw_0110_0010_0011.zip`（V1.1）  
改动文件：`image_transition.v`、`user_control.v`、`osd_overlay.v`、`osd_status_layout.v`、`top_tf_hdmi_audio.v`  
未改动：SD/BMP、SDRAM 缓存、缩放、PLL、约束、`.al` 工程文件清单（仍然没有新增源文件）

## 1. 新增/变化的 SW 编码

| SW | 设置项 | K3 循环 | 默认 |
|---|---|---|---|
| `0100` | 转场效果 | 直接切换 → 淡出淡入 → 水平滑动 → **风车旋转** | 直接切换 |
| `1010` | **亮度** | 0 → 1 → … → 10 → 0（11 档，5 为中性，每档 ±16 亮度偏移） | 5 |
| `1011` | **对比度** | 0 → 1 → … → 10 → 0（11 档，5 为中性 1.0 倍，范围 0.49~1.51 倍） | 5 |

`0001`、`0010`、`0011`、`0101`、`0110`、`0111`、`1000` 保持 V1.1 的行为不变。

## 2. 风车旋转转场（SW=0100 第 4 档）

`image_transition.v` 增加 `MODE_ROTATE`。几何算法如下（不需要除法、不需要 ROM）：

```
dx = x - 320, dy = y - 240
m  = min(|dx|,|dy|),  M = max(|dx|,|dy|)
可见条件： m * 256 < M * T          （M=0 时恒可见）
```

等价于“以画面中心为顶点、以 ±x/±y 为对称轴的 4 片扇形，张角 < 45° 内可见”。
`T` 从 `ROT_MAX(320)` 递减到 0 就是四片叶片**从满屏收拢到中心**（转场前半段，画面收黑），
再从 0 递增回 320 就是**从中心张开**到满屏（转场后半段，新图揭开）。
`T` 每帧按 `320/frames_total` 变化，和淡入淡出、滑动共用同一套 15/30/60 帧时长设置。

实现代价：每像素 1 个 10×10 乘法器 + 若干比较器，`video_clk`（25 MHz）下时序压力很小。
注意这是**扇形擦除**，不是把图像本身做旋转（这条流水线是行缓存顺序读出，做不到逐像素任意角度取源）。

## 3. 亮度 / 对比度（SW=1010 / 1011）

### 3.1 算法

```
对比度增益 K：126~386（256 = 1.0 倍）        亮度偏移 B：-80~+80
基准像素   base = (c * K + 128) >> 8         输出 = clamp(base + 128 - K/2 + B)
```

为了让逐像素乘法器数量**不增加**，把淡化的 `gain` 一起折叠进去（两者都是每帧常量）：

```
KG = (K * gain) >> 8
OG = ((128 - K/2 + B) * gain) >> 8
输出 = clamp( ((c * KG + 128) >> 8) + OG )
```

- `gain=256`（正常显示）时 `KG=K`、`OG=128-K/2+B`，就是上面的亮度/对比度公式；
- `gain=0`（淡出结束）时 `KG=OG=0`，**仍然准确回到全黑**，不会出现“淡出到灰”；
- 逐像素仍然只有原来的 3 个 9×9 乘法器，只在每帧更新时多做两次小乘法。

`brightness` / `contrast` 在帧消隐边界（`frame_tick`）锁存，一帧内不变。

### 3.2 字幕提示

拨到 SW=1010/1011 时，画面底部（第 448~463 行）居中显示：

```
BRIGHTNESS:10      CONTRAST: 5
```

- 该提示不受 `0001` 文字显示模式影响，拨到对应设置项就显示，拨走就消失；
- 显示期间滚动字幕自动让位（不重叠）；
- 状态栏第三行改成两位数字，`SW:1010 V=10` 不会再显示成 `A`。

## 4. 诊断功能的让位

`1010` / `1011` 原来是诊断页编码，现在被亮度/对比度占用：

- `diagnostic_page` 改为 `SW==1001 || SW>=1100`，拨 1010/1011 时数码管恢复显示正常状态；
- 原来 `SW=1010` 触发的 SDRAM“灰阶”诊断位改为恒 0（`diagnostic_gray_requested` 不再置起）。

如果要保留那个诊断，把 `top_tf_hdmi_audio.v` 里 `u_scale_mode_cdc` 的 `1'b0` 换回一个空闲编码即可。

## 5. 板上操作

1. TD 重新综合实现、下载（本包不含 bitstream）。
2. **风车转场**：SW=`0100` 连按 K3 三次切到第四档（状态栏 `V=4`），按 K2 切图；
   应看到画面以中心为顶点、四片扇形收拢成黑，再从中心张开成新图。
3. **亮度**：拨 SW=`1010`，底部出现 `BRIGHTNESS: 5`，按 K3 逐档变化，0~10 循环，画面同步变亮/变暗。
4. **对比度**：拨 SW=`1011`，底部出现 `CONTRAST: 5`，按 K3 逐档变化，画面层次变强/变弱。
5. 亮度/对比度与转场、缩放互不影响；亮度为非中性时切图，黑幕仍然是纯黑（不会发灰）。
6. K1 复位：亮度/对比度回到 5，转场回直接切换，文字/滚动/滑动方向回到 V1.1 的默认值。

## 6. 需要注意

- **本包没有重新生成 bitstream**：本机没有安装 Anlogic TD，需要你自己在 TD 里重新跑综合、实现、布线，
  并复核资源与时序。新增逻辑预估很少（1 个 10×10 乘法器 + 约十几位比较/选择逻辑），
  但已有工程 DSP 已用到 22/29、LUT 约 55%，请以 TD 报告为准。
- 亮度/对比度是**对整幅图像**做线性变换，不改变 OSD 文字（文字仍是纯黑）。
- 对比度 0 档会把黑抬成灰（约 65），属于正常的“低对比度发灰”效果；想快速恢复正常按到 5。
