3. 保留未屏蔽版本。若要复现用户批准的异步分组实验，另建副本，再检查并应用async_exception.patch。
4. 重新综合、布局布线和板测；生成的bit不保证与已记录bit逐字节一致。

第一批提前寄存扇区数，不改变扫描事务或像素延迟。第二批仅在FIFO检查状态寄存数据充足判断、其余状态清零，仲裁仍使用当前读忙信号；每突发检查增加一拍（8ns），突发内吞吐和RGB/DE/HS/VS延迟不变。原控制器非256整数倍尾突发不能报告完成的限制保留；640×480=307200可整除256。
