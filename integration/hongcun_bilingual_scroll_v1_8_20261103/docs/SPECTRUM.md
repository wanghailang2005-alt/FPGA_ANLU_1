# V1.6 紧凑音频频谱

对应题目要求：“结合音频数据生成频谱或波形显示，叠加于视频画面，增强交互展示效果。”本版采用频谱柱，由实际输出PCM计算得到，没有使用固定动画模拟声音。

## 操作与布局

SW4..SW1=`1001`进入，其他档退出；模式在垂直消隐切换，避免帧内改变布局。原`1001`棋盘诊断图由本模式取代，K3在此档仍无操作。K2翻图、K4轮播及其他设置不变。

| 区域 | 坐标（含边界） | 呈现 |
|---|---|---|
| 图文主区 | y=0..383 | 上方80%，不叠加频谱或底部字幕 |
| 左下字幕卡 | x=16..335, y=384..447 | 原图通道右移2位的深色半透明底板 |
| 逐图中文 | x=16..335, y=400..415 | 320px窗口，近白色16×16点阵，保留滚动速度/方向及随图切换 |
| 逐图英文 | x=48..303, y=424..439 | 256px标题窗口，在左卡中居中 |
| 右下频谱卡 | x=352..623, y=384..447 | 272×64px，标题AUDIO TEST |
| 频谱柱 | x=360..615, y=404..443 | 32柱，节距8px/柱宽6px，最高40px |
| 最底滚动提示 | y=448..463 | 原欢迎文字或亮度/对比度提示，不与频谱叠加 |

柱体青绿`38d6b4`，峰值淡青`bef7e8`。柱高快速上升、缓慢回落，峰值保持后缓慢下降。静音时柱子及峰值逐渐归零。素材制作建议将重要图文放在y<384区域；图像缓冲仍保持640×480，不增加缩放或裁剪步骤。

退出模式后，中文恢复全宽，英文恢复原x=160..415窗口与黑色文字；中英开关、底部滚动条、固定状态及参数提示沿用既有控制。

## 实现范围

- FFT和分析模块直接复用已上板版本：512点、16位定点、周期Hann窗、共享一个16×16乘法器、32频带。
- 原分析高度0..160右移两位得到0..40px，显示层不增加DSP乘法器。
- 频带按低频到高频排列，保留原频带映射；显示值为近似幅度和对数压缩，不是校准声压级或dB。
- 新增逻辑仅使用现有25MHz `video_clk`与现有复位，没有新增PLL或跨域接口。原I2S发生/接收和HDMI音频载荷不变。
- 顶层串接频谱层；OSD新增compact布局输入和字幕裁剪/配色；工程清单加入三个AUDIO_VIS源文件。
- 汉字点阵改为2048×16同步BRAM ROM，减少组合字模选择逻辑；原93个字形及显示三拍延迟保持。全部2048行与原函数逐行比较一致，1488行为有效字形。
- 对原125MHz缓存观察行校验路径增加一拍状态上报流水线，修复原报告中的诊断路径瓶颈。缓存像素、命令、仲裁及握手部分与基线逐字一致，见`spectrum_evidence/cache_timing_patch.json`。

### 上板检查

下载根目录命名bit，K1复位，等待TF图片显示，拨到1001。确认右下32柱随测试音阶变化，左下中文/英文完整，最底滚动条独立；K2切图后字幕随图更新。拨回0000，应恢复原字幕布局；再检查原有转场、缩放、亮度和轮播操作。

旧版已板测不等同于这个新bit通过板测。原SDRAM时钟例外与缺失的接口时延约束没有在本次扩大或修改，当前约束下的时序结果不代表完整接口电气验证。
