# 统一按键与拨码规划

更新：2026-10-28。切图、字幕、轮播、转场及三档时长已获用户板测确认；预留功能仍按下表区分。异步实验的约束边界见[最新记录](2026-10-28.md)。

## 按键职责

| 板上按键 | 功能 |
|---|---|
| K1 | 复位，恢复默认参数 |
| K2 | 下一张，使用当前转场设置；加载或转场忙时忽略、不排队 |
| K3 | 修改SW选中的设置项，每次按下操作一次，不长按连发 |
| K4 | 自动轮播启停；关闭后当前操作完成再停，至少两张有效图片 |

代码端口key1对应K2/B2，key2对应K4/C1，key3对应K3/B1，rst_n对应K1/A2。

## 拨码编码

编码按SW4 SW3 SW2 SW1阅读，即sw[3:0]，SW1为最低位。

| SW | 设置项 | K3循环顺序 | 本次候选状态 |
|---|---|---|---|
| 0000 | 正常播放 | 无操作 | 已实现 |
| 0001 | 文字模式 | 关闭→固定OSD→滚动字幕→同时显示 | 规划，未接入控制；当前保持IMG/AUTO与字幕同时显示 |
| 0010 | 字幕速度 | 慢→中→快 | 规划，未接入 |
| 0011 | 字幕方向 | 向左→向右 | 规划，未接入 |
| 0100 | 转场效果 | 直接切换→淡出淡入→滑动揭幕 | 已实现 |
| 0101 | 转场时长 | 短→中→长 | 已实现，默认中 |
| 0110 | 滑动方向 | 向左→向右 | 预留，无操作 |
| 0111 | 图片适配 | 原尺寸居中→等比例留边→铺满裁剪 | 待缩放接入 |
| 1000 | 插值算法 | 最近邻→双线性 | 首轮保持最近邻，未接入 |
| 1001～1111 | 扩展 | 无操作 | 预留 |

只有0100、0101下K3会修改参数；其余未开放编码无副作用。SW只选择设置项，拨动本身不修改值，各参数独立保存。当前切图源码定义上拨为1，实际方向需在板上核对。SW1=C8、SW2=C7、SW3=C6、SW4=C5。

## 短、中、长如何计时

| 档位 | 每段帧数 | 约60Hz下单段时间 | 淡出+淡入／遮盖+揭开 |
|---|---:|---:|---:|
| 短 | 15 | 0.25秒 | 约0.5秒+提交等待 |
| 中 | 30 | 0.5秒 | 约1秒+提交等待 |
| 长 | 60 | 1秒 | 约2秒+提交等待 |

时间按实际帧率计算，单段T=N/fps，不按按键按住时间计算。检测到VS帧边界时更新一次亮度或滑动边界。直接切换不使用动画时长。默认中，因此复位后在0101下按K3实际为长→短→中。

转场在接受请求时锁存效果/时长，中途修改只影响下一次转场；显示参数未来按帧消隐边界提交。当前淡入淡出为经黑场切换，滑动为黑幕遮盖/揭开，不是两张图同时混合或推移。

## 与原切图独立工程的差异

- 原切图工程忙时缓存一次K2请求，本次集成改为忽略，符合统一规划。
- 原切图工程K2会关闭轮播；本次以OSD成功版为底座，K2不主动关闭轮播。K4独立负责轮播启停。
- SW/K3只处理转场参数；OSD模式/速度/方向仍待后续统一控制扩展。
