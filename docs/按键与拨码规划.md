# 按键与拨码规划（V1.5 当前版）

更新：2026-11-03。适用工程：zoom_animation_per_image_captions；用户已确认全部功能上板测试通过。本文按当前 user_control.v、top_tf_hdmi_audio.v 和 sd_card_bmp.v 核对。

[版本入口](../integration/per_image_captions_v1_5_20261103/README.md) · [板测及实现记录](../integration/per_image_captions_v1_5_20261103/docs/BOARD_TEST_20261103.md) · [旧版规划存档](history/按键与拨码规划_20261029.md)

拨码顺序为 **SW4 SW3 SW2 SW1**，拨上为 1。先拨到对应功能，稳定后按 K3 调整；参数独立保存，长按不连发。

| 按键 | 功能 |
|---|---|
| K1 | 系统复位，恢复默认设置（RTL 端口 rst_n） |
| K2 | 下一张图片（RTL 端口 key1） |
| K3 | 调整拨码选中的设置（RTL 端口 key3） |
| K4 | 开启/关闭自动轮播（RTL 端口 key2，默认关闭） |

| SW | 功能 | K3 循环顺序 | 默认 |
|---|---|---|---|
| 0001 | 普通文字 | 关闭 → 固定状态 → 底部滚动条 → 两者同时 | 两者同时 |
| 0010 | 滚动速度 | 慢 1 → 中 2 → 快 4 像素/帧 | 慢 |
| 0011 | 滚动方向 | 向左 ↔ 向右 | 向左 |
| 0100 | 转场 | 直接 → 淡出淡入 → 水平滑动 → 风车旋转 → 垂直擦除 → 百叶窗 → 圆形光圈 → 方块溶解 | 直接 |
| 0101 | 转场时长 | 15 → 30 → 60 帧 | 30 帧 |
| 0110 | 转场方向 | 左/右；也控制垂直擦除方向 | 向左 |
| 0111 | 最近邻缩放 | 原尺寸居中 → 等比例留边 → 铺满裁剪 | 原尺寸 |
| 1000 | 双线性缩放 | 原尺寸居中 → 等比例留边 → 铺满裁剪，带缩放动画 | 原尺寸 |
| 1010 | 亮度 | 0～10 递增，10 后回 0 | 5，中性 |
| 1011 | 对比度 | 0～10 递增，10 后回 0 | 5，中性 |
| 1100 | 逐图双语字幕 | 关闭 → 中文 → 英文 → 双语 | 双语 |
| 1001 | 棋盘诊断图 | 拨到此档直接显示，无需 K3；拨回其他档退出 | — |
| 0000、1101～1111 | 未分配设置 | K3 无操作，继续显示当前图片 | — |

复位默认双语，因此第一次在 1100 按 K3 会关闭字幕。0001 不控制逐图字幕；0010/0011 同时影响中文字幕和底部滚动条。缩放时等待当前动作完成再按 K3；4:3 图片的留边与铺满目标相同。

| 显示层 | 位置/内容 |
|---|---|
| 固定状态 | 左上角 IMG / AUTO / SW 与设置值 |
| 中文 | y=400～415，16×16 点阵跑马灯，切图后重新进场 |
| 英文 | y=424～439，32 字符窗口静态标题 |
| 底部条 | y=448～463，欢迎文字；调节亮度/对比度时显示参数提示 |

| 图片序号 | 默认场景 | 英文标题 |
|---|---|---|
| 1 | 宏村月沼 | HONGCUN MOON POND |
| 2 | 承志堂木雕 | CHENGZHI HALL CARVING |
| 3 | 历史老照片 | HONGCUN OLD PHOTOS |
| 4 | 徽派马头墙 | HUI HORSE-HEAD WALL |

更换图片素材需要同步更新字幕；生成工具的维护问题见本版板测记录。

## 按键与引脚

| 板上按键 | RTL 端口 | 引脚 |
|---|---|---|
| K1 | rst_n | A2 |
| K2 | key1 | B2 |
| K3 | key3 | B1 |
| K4 | key2 | C1 |

SW1=C8、SW2=C7、SW3=C6、SW4=C5；SW1 是最低位。K3 与拨码均有约 20 ms 消抖/稳定滤波，拨码正在变化时的 K3 操作会被忽略。

K2 在图片加载或转场忙时被忽略，不排队；手动切图不主动关闭自动轮播。K4 需要扫描结束且至少发现两张有效图片才能切换轮播；关闭后已开始的操作继续完成。自动轮播在空闲显示约 1 秒后触发下一张，实际换图间隔还包括加载与转场时间。缩放动画忙时 0111/1000 的 K3 调整被忽略。

## 转场时长与方向

| 档位 | 单段帧数 | 约 60 Hz 单段时间 | 淡出+淡入或遮盖+揭开 |
|---|---|---|---|
| 短 | 15 | 0.25 秒 | 约 0.5 秒 + 加载/提交等待 |
| 中 | 30 | 0.5 秒 | 约 1 秒 + 加载/提交等待 |
| 长 | 60 | 1 秒 | 约 2 秒 + 加载/提交等待 |

时间按实际帧率计算；直接切换不使用动画时长。默认中档，因此复位后第一次在 0101 按 K3 会变为长档。转场效果、时长和方向在请求时锁存，中途调整影响后续请求。水平滑动是黑幕遮盖/揭开；0110 也控制垂直擦除从上方或下方保留可见区域。

## 状态文字与默认值

固定状态文字位于左上角。V 显示当前设置值：亮度/对比度直接显示 0～10；其他已分配设置显示内部编码加 1；0000、1001、1101～1111 显示 0。最近邻与双线性分别记忆自己的三档设置，按对应档位 K3 时选择算法并前进一档。

复位默认：轮播关闭、转场直接、时长中、缩放原尺寸/最近邻、普通文字两者同时、滚动慢速向左、亮度/对比度 5、逐图字幕双语。复位不会改变物理拨码位置；如果保持在 1001，稳定后仍显示诊断棋盘。

## 历史版本区别

2026-10-29 的音频可视化独立版本使用 1001 进入 FFT 页面；当前 V1.5 同一编码为棋盘诊断图，未合入该 FFT 页面。旧版“文字控制待接入”“只有 0100/0101 有效”“1000 只切换插值算法”等描述均不适用于本版。旧文档已存档，历史实现和板测结论保持原日期语境。
